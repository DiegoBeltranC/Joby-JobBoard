# UI

Scope: the component system used by bolsa-trabajo. It **is shadcn/ui (new-york style) + Radix** —
reuse and extend it; do not hand-roll primitives that shadcn already provides.

## Components

- Primitives live in `src/components/ui` (installed so far: `button`, `input`, `password-input`,
  `card`, `dialog`, `alert-dialog`, `popover`, `command`, `checkbox`, `label`, `sonner`). They are
  generated by the shadcn CLI and configured in `components.json` (`style: new-york`, `rsc: true`,
  `iconLibrary: lucide`, aliases `@/components/ui`, `@/lib/utils`).
- **Need a primitive that isn't there yet** (e.g. `select`, `tabs`, `sheet`, `dropdown-menu`,
  `tooltip`, `table`, `badge`, `avatar`)? Add it with the CLI:
  ```bash
  npx shadcn@latest add sheet tabs select
  ```
  Then adapt tokens/props if needed. Don't paste a bespoke reimplementation.
- Composite/product components (modals, shells, cards specific to Joby) live in `src/components/*`
  (PascalCase) and `src/components/empresa/*`, and compose the `ui` primitives.

## Variants — `cva` + `cn()`

shadcn components use **`class-variance-authority`** for variants and `cn()` (`@/lib/utils`) to merge:

```tsx
import { cva, type VariantProps } from "class-variance-authority";
import { cn } from "@/lib/utils";

const badgeVariants = cva("inline-flex items-center rounded-md px-2 py-0.5 text-xs font-medium", {
  variants: {
    variant: {
      default: "bg-primary text-primary-foreground",
      secondary: "bg-secondary text-secondary-foreground",
      destructive: "bg-destructive text-white",
      outline: "border text-foreground",
    },
  },
  defaultVariants: { variant: "default" },
});
```

- Follow the existing button/card patterns: `data-slot` attributes, `focus-visible:ring-ring/50`,
  `aria-invalid:*` styling, `asChild` via Radix `Slot` where composition is useful.
- Sizes/variants are named consistently (`default`, `sm`, `lg`, `icon`, …) — mirror `button.tsx`.

## Tokens, not raw colors

Style with the **semantic token classes** backed by the CSS variables in `globals.css`
(`bg-background`, `text-foreground`, `bg-primary`, `bg-muted`, `text-muted-foreground`,
`border-border`, `bg-card`, `ring-ring`, …). Never hardcode hex or use raw Tailwind palette colors
(`bg-green-600`, `text-gray-500`). See design-system.md for the full token list.

## Toasts, icons, theme

- Notifications: **`sonner`** — the `<Toaster />` is mounted in the root layout; call `toast.success` /
  `toast.error` from client components.
- Icons: **`lucide-react`**.
- Dark mode: class-based via **`next-themes`** (`.dark`). Token classes cover both themes; reach for
  `dark:` only when a token can't express the difference.

## Rule

- Reuse `@/components/ui` before building anything; add missing primitives via the shadcn CLI.
- New components should look like they were generated/composed the same way as the existing ones
  (cva variants, `cn()`, tokens, `data-slot`).
- Do **not** introduce a competing UI kit (MUI, Chakra, Mantine, hand-rolled primitives) or a second
  icon library.

See design-system.md for tokens (colors, radius, typography) and responsive.md for layout rules.
